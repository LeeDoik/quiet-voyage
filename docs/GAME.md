# 함께 흐르는 바다 (Quiet Voyage) — 게임 문서

끝없는 바다를 천천히 항해하며 섬과 고래를 만나는 웹 게임이다. 여러 사람이 같은 바다에 접속해 말없이 빛으로 인사한다.

이 문서는 게임의 모든 정보를 한곳에 모은다. 실행·배포 명령과 서버 프로토콜의 바이트 단위 명세는 [README.md](../README.md)가 원본이고, 여기서는 요약만 한다. 숫자는 코드에 있는 값이다.

## 2. 디자인 원칙

- **조용한 항해.** 전투, 점수, 경쟁이 없다. 바람을 타고 가다 섬, 생물, 노을, 다른 배를 만난다.
- **모두 같은 바다.** 섬, 생물, 날씨, 낮밤은 고정 시드(`WORLD_SEED = 20261105`)와 공유 시계로 정해진다. 같은 좌표, 같은 시각이면 모든 플레이어가 같은 장면을 본다. 그래서 시뮬레이션 코드에서 `Math.random`을 쓰지 않는다. 기기마다 달라도 되는 것(출발 위치, 배 이름, id)만 `crypto` 난수를 쓴다.
- **말 대신 빛.** 채팅이 없다. 빛물결, 나란히 항해하기, 병 편지로만 소통한다. 병 편지는 정해진 문구를 고르거나 60자까지 직접 쓸 수 있고, 직접 쓴 편지는 서버가 욕설·비방·연락처를 검사한 뒤에만 띄운다.
- **찾아서 발견하기.** 생물은 대부분 물속에 있다. 숨 물보라, 맴도는 바닷새, 지느러미, 물튀김을 보고 찾는다.
- **HUD는 캔버스.** DOM UI가 없다(편지를 쓸 때만 화면에 보이지 않는 입력 칸을 둔다. 한글 입력기와 휴대폰 키보드가 필요해서다). 모든 글자와 패널은 캔버스 HUD(`window.__studio.hud`)로 그린다. 항해 일지처럼 크림색 종이에 잉크로 쓴 모양이고, 밤에는 등불 아래 종이처럼 어두워진다.

## 3. 조작

| 동작 | 키보드 | 휴대폰 |

| 빠르게 / 천천히 | W·↑ / S·↓ | ▲ / ▼ |
| 방향 | A·D / ←·→ | ◀ / ▶ |
| 항해 노트 | J (ESC로 닫기) | 노트 |

| 환경설정(소리 종류별 음량) | O, 오른쪽 위 배지, ↑↓ 고르기 · ←→ 조절 · 끌기 | 설정 |

| 동행 연습(오프라인) | H | 동행 |

| 그래픽 / 성능 패널 (개발자만) | G / P | — |

처음 들어온 사람에게는 튜토리얼이 상황에 맞춰 한 줄씩 나온다(`interface.js` TUTORIAL): 출항(W) → 방향(A·D) → 휠 줌 → 첫 섬·생물을 만나면 노트(J)·도감(K) → 1분 반 뒤 자동 항해(T) → 다른 배가 가까우면 빛물결(E) → 2분 반 뒤 병 편지(B) → 노을이면 사진(C) → 4분 뒤 설정(O). 한 번에 한 줄, 그 키를 쓰면 사라지고 20초가 지나도 사라진다. 지난 줄은 브라우저에 기억해서 다시 보여 주지 않는다.

아무 키나 누르거나 화면을 누르면 출항한다. 처음 몇십 초 동안 "바람을 타고 나아가기", "천천히 방향 바꾸기", "빛으로 인사하기" 안내가 차례로 뜬다.

## 4. 세계

### 크기와 구조

- 지도는 반지름 30 km의 바다다. 가장자리 2.5 km에서 안개가 짙어지고 배가 안쪽으로 밀린다. 안개 끝에 닿으면 "안개의 끝"이 발견으로 기록된다.
- **홈 바다**(반지름 약 950 m)는 손으로 만든 섬 3개(첫 바람섬, 긴 등섬, 높은 숲섬)와 "고요한 만"을 그대로 둔다. 고요한 만은 두 곶이 얕은 안쪽 해변을 감싼 지형이다.
- 그 바깥은 800 m 청크마다 고정 시드로 섬, 생물 무리, 병을 만든다. 배 주변 1.9 km 안의 섬만 한 프레임에 하나씩 짓고, 2.4 km 밖으로 멀어지면 해제한다.
- 웹에서는 플레이어마다 홈 바다 주변 180~2,780 m의 서로 다른 곳에서 출발한다. 한 지점에 몰리지 않게 하려는 것이다.

### 섬

| 종류 | 비율 | 특징 |
|---|---|---|
| 숲섬 (green) | 34% | 나무가 자라는 언덕섬 |
| 바위섬 (rock) | 20% | 바위, 바닷새 둥지 |
| 산호 모래섬 (atoll) | 20% | 고리 모양 모래섬 |
| 모래톱 (sandbar) | 17% | 낮은 모래등, 바닷새가 쉰다 |
| 화산섬 (volcano) | 9% | 봉우리섬 |

- **컨셉 섬**(`island-concepts.js`, `island-decor.js`): 모든 섬에 컨셉이 하나씩 있다. 섬 종류에 맞는 것 중에서 섬 시드의 해시로 고르기 때문에 누구에게나 같다. world-gen의 난수 순서는 그대로라서 지도 배치도 바뀌지 않는다. 컨셉이 이름의 끝말이 된다(예: 은빛귤섬 / Silver Orchard Isle). 배가 해안 140 m 안에 들면 이름과 컨셉 한 줄이 뜨고 항해 노트에 남는다.

| 컨셉 | 섬 | 보이는 것 |
|---|---|---|
| 풍차섬 | 숲 | 언덕마다 풍차 2~3개. 바람 세기에 따라 날개가 돈다 |
| 마을섬 | 숲 | 알록달록한 지붕의 집 4~6채(밤에 창이 켜짐), 굴뚝 연기, 나무 부두와 매어 둔 배, 생선 건조대 |
| 정자섬 | 숲·화산 | 꼭대기의 육각 정자(처마가 들린 지붕, 단청 띠), 해안에서 오르는 디딤돌 |
| 등대섬 | 숲·바위 | 붉은 띠 등대(밤에 불빛이 돈다), 등대지기의 집과 하얀 울타리 |
| 동백섬 | 숲 | 붉은 동백나무 40그루와 떨어진 꽃잎, 벤치 |
| 귤섬 | 숲 | 검은 돌담 밭 4곳에 줄지어 선 귤나무 |
| 옛터섬 | 숲·바위 | 꼭대기에 무너진 돌기둥의 원, 아직 선 아치, 바닥돌 |
| 별섬 | 숲 | 꼭대기의 하얀 천문대(밤에 지붕 틈이 빛남) |
| 새섬 | 바위·모래톱 | 새똥으로 하얀 줄이 진 바위, 둥지와 알, 앉아 있는 바닷새 |
| 구멍바위 | 바위 | 바다 쪽으로 뚫린 큰 바위 아치와 바위 기둥 |
| 돌탑섬 | 바위·모래톱 | 돌탑 16개 |
| 야자섬 | 산호 | 야자수 사이 줄무늬 해먹, 초가 오두막, 조개와 불가사리 |
| 난파섬 | 산호·모래톱 | 모래에 얹혀 기운 난파선, 드러난 늑골, 부러진 돛대 |
| 불섬 | 화산 | 분화구에서 바람 따라 흐르는 연기, 밤에 빛나는 분화구, 김이 나는 온천, 검은 모래 |

- 홈 섬은 첫 바람섬=풍차, 긴 등섬=마을, 높은 숲섬=정자다.
- **섬의 대답**: 빛물결(E)이 섬 해안 220 m 안에서 일어나면 가장 가까운 섬이 대답한다. 내 빛물결이든 다른 배의 빛물결이든 같다. 빛물결은 이미 네트워크로 공유되므로 근처의 모두가 같은 대답을 보고, 통신량은 늘지 않는다.
  - 대답은 0.6초에 올라와 16초 머물고 24초에 사라진다.
  - 섬에서 낮게 올라가는 아르페지오가 울린다(`sfx.reply`).
  - 내 빛물결이면 "섬 이름 + 대답 한 줄"이 뜨고, 항해 노트에 '{섬}의 대답'으로 한 번 남는다.
  - 처음 만난 섬 세 곳에서는 "E 빛물결을 보내면 섬이 대답해요"라는 안내가 붙는다.
  - 컨셉별 대답:

| 컨셉 | 대답 |
|---|---|
| 풍차섬 | 날개가 빠르게 돈다(각도를 적분해서 속도만 바뀐다), 창에 불 |
| 마을섬 | 창과 부두 등불이 켜지고 굴뚝 연기가 짙어지며 따뜻한 빛이 오른다 |
| 정자섬 | 처마 끝 붉은 등 여섯이 켜지고 연분홍 꽃잎이 날린다 |
| 등대섬 | 낮에도 불빛을 켜고 더 빨리 돌린다 |
| 동백섬 | 붉은 꽃잎이 바다 위로 흩날린다 |
| 귤섬 | 귤밭 위로 주황빛이 반짝이며 오른다 |
| 옛터섬 | 돌기둥의 새김 띠가 푸르게 빛나고 푸른 빛이 맴돌며 오른다 |
| 별섬 | 천문대에서 하늘로 빛줄기가 서고 별빛이 솟는다 |
| 새섬 | 바닷새 무리가 날아올라 바위 위를 맴돈다 |
| 구멍바위 | 아치 안에 빛이 고여 맴돈다 |
| 돌탑섬 | 돌탑 꼭대기마다 작은 불이 켜진다 |
| 야자섬 | 야자수 사이로 반딧불이 떠오른다 |
| 난파섬 | 등불이 켜지고 금빛이 반짝인다 |
| 불섬 | 분화구가 밝아지고 연기가 짙어지며 불티를 뿜는다 |

  - 구현: 섬마다 자기 조명 재질(창·등불 `glow`, 새김·돌탑 불 `rune`, 분화구 `lava`)을 가져서 그 섬만 켜진다. 입자(꽃잎, 불티, 반딧불, 새떼)는 공유 시계로 셰이더에서 한 번 재생한다. 빛마다 후광 스프라이트가 있어서 멀리서도 최소 크기로 보인다. 그래서 밤에는 먼 섬의 창 불빛도 보인다(블룸이 없기 때문).
- 랜드마크(풍차, 집, 정자, 천문대, 아치, 난파선, 돌탑, 연기)는 섬이 로드된 1.9 km 안에서 늘 보인다. 덤불·꽃·작은 소품은 나무처럼 1.15 km 안에서만 그린다. 랜드마크가 있는 섬은 꼭대기에 나무를 심지 않는다.
- **모든 섬의 바닥**: 해안선을 따라 바위가 있다(화산은 현무암, 산호섬은 밝은 돌). 가파른 곳엔 노두가 드러나고, 숲섬에는 덤불과 풀숲, 들꽃 무리, 해변의 유목이 있다. 지형에는 능선·골짜기(ridged noise)와 잔기복이 있다. 색은 볕에 마른 풀빛, 물가의 젖은 모래, 화산의 재·검은 모래, 산호섬의 흰 모래, 새섬의 새똥으로 칠한다.
- 정적인 것은 섬마다 재질별로 한 메시로 합친다. 움직이는 것(풍차 날개, 연기)만 따로 두고, 연기는 공유 시계로 셰이더에서 움직인다.
- 개발용 데모 `visit-<컨셉>`은 가장 가까운 그 컨셉의 섬 앞(해를 등진 쪽)으로 데려간다.
- 이름은 접두어와 컨셉(없으면 종류별 접미어)을 시드로 골라 만든다. 한국어와 영어 이름이 한 쌍이라 언어가 달라도 같은 섬이다.
- 지형 메시의 해안선은 충돌 모양과 같다. 바다 셰이더도 가까운 섬 6개의 해안 모양을 받아 얕은 물빛과 파도 거품을 그린다.

### 해양 생물

| 생물 | 출현 | 행동 |
|---|---|---|
| 돌고래 | 먼바다·섬 근처, 4~9마리 | 무리로 숨 쉬며 솟는다. 움직이는 배의 뱃머리 물결을 타러 다가온다 |
| 혹등고래 | 주로 먼바다, 1~3마리 | 높은 숨 물보라 네 번, 꼬리 들고 깊이 잠수, 가끔 통째로 솟구친다. 노래한다 |
| 범고래 | 먼바다, 3~6마리 | 키 큰 등지느러미, 가족끼리 나란히 |
| 바다거북 | 주로 섬 근처, 1~2마리 | 숨 쉬러 잠깐 머리를 내민다 |
| 쥐가오리 | 1~3마리 | 날 듯 헤엄치다 뛰어올라 뒤집힌다 |
| 날치 | 7~13마리 | 배가 다가오면 수면 위를 수십 미터 미끄러진다 |
| 바닷새 | 돌고래·날치 무리 위, 바위섬·모래톱 | 먹이 있는 물 위를 맴돈다. 새가 모인 곳 아래에 생물이 있다 |

- 생물 무리는 청크마다 시드로 정하고, 섬에서 260 m 안이면 섬 근처 분포를 쓴다.
- 숨 쉬기, 솟구치기 같은 순간은 공유 시계로 정해서 모두에게 같은 때 일어난다.

**모델**(`tools/blender/marine_life.py` → `public/assets/blender/marine-life/marine-life.glb`, `npm run models`)

- Blender 5.2 스크립트가 7종을 코드로 만든다. 몸통은 해부학 단면을 촘촘히 이어(loft) Subdivision으로 매끈하게 하고, 지느러미·꼬리·날개는 NACA 대칭 익형 단면을 이어 뿌리는 두껍고 가장자리는 얇다. 무늬는 정점 색이다: 돌고래의 물결진 등빛·옆구리 띠·눈·입선, 범고래의 눈 무늬·회색 안장·옆구리 흰 무늬·흰 꼬리 아래, 혹등고래의 목 주름(형태와 선)·머리 혹·울퉁불퉁한 4 m 흰 가슴지느러미·톱니진 꼬리, 바다거북의 등판(가운데 5·양옆 4·가장자리 11, 눌린 이음선과 햇살 무늬), 쥐가오리의 머리 앞 두 엽·흰 어깨 무늬·배의 아가미 틈과 점, 날치의 줄무늬 날개와 긴 아래 꼬리, 갈매기의 끝이 검은 날개와 붉은 점 부리.
- 폴리곤(삼각형): 돌고래 6.3천, 범고래 1.1만, 혹등고래 1.8만, 바다거북 9.5천, 쥐가오리 7.2천, 날치 1.8천, 갈매기 2.2천. 한꺼번에 많이 나오는 작은 생물일수록 가볍다.
- 얼굴: 모든 종에 눈알 형상을 단다(`add_eyes`, 실제보다 크게). 어두운 반구에 위·앞쪽 큰 하이라이트와 아래 작은 반짝임을 칠하고, 몸(거북은 머리)과 함께 움직인다(part `EYE`). 돌고래·거북은 웃는 입선과 옅은 볼터치, 쥐가오리는 앞쪽에 넓은 입선이 있다.
- 애니메이션도 Blender 스크립트가 만든다. 종마다 한 주기의 움직임을 정의한다(`ANIMS`): 척추는 머리에서 꼬리로 흐르는 물결로 휘고 단면이 그 곡선을 따라 돌며, 지느러미·날개는 뿌리를 관절 삼아 돈다.
  - 돌고래·범고래·혹등고래: 위아래 꼬리 젓기. 범고래는 등지느러미가 살짝 흔들리고, 혹등고래는 긴 가슴지느러미로 노를 젓는다.
  - 바다거북: 앞지느러미로 물속을 난다(위·앞으로 올렸다가 앞 가장자리를 숙여 아래·뒤로). 뒷지느러미로 방향을 잡고, 고개를 끄덕이며, 등딱지가 오르내린다.
  - 쥐가오리: 날개 앞 가장자리에서 뒤·끝으로 흐르는 물결로 날갯짓하고, 몸통은 반대로 까딱이며, 꼬리가 좌우로 끌린다.
  - 날치: 좌우 꼬리 치기와 날개 떨림.
  - 갈매기: 어깨로 날갯짓하고, 올릴 때는 손목에서 날개 끝을 접고 내릴 때는 편다. 몸이 살짝 오르내린다.
- 주기를 24프레임 샘플링해 정점마다 푸리에 계수(위치 2차, 법선 1차)로 굽는다(오차 0~5 mm). 내보낸 뒤 축을 glTF 기준으로 바꾸고 부호 있는 8비트로 줄여 `_A1 _B1 _A2 _B2 _N1 _M1` 속성과 메시 `extras.swim`(배율)에 넣는다. 게임 셰이더(`marine-life.js` bakedMaterial)는 `p + A1·cos φ + B1·sin φ + A2·cos 2φ + B2·sin 2φ`로 재생한다. φ는 개체별 위상이고, 세기는 `aSwim.y / ref`라서 활공하는 새·날치는 약하게 움직인다. 미리보기 프레임은 `blender -b -P tools/blender/marine_life.py -- --frames <폴더>`로 렌더한다.
- 게임은 GLB를 불러와 종마다 메시와 재질을 바꿔 끼운다. 못 불러오면 코드로 만든 모양과 예전 꼬리 흔들기 셰이더(`aBend`)를 그대로 쓴다.

**돌고래 뱃머리 타기**(`public/src/dolphin-ride.js`)

- 무리가 배에서 110 m 안에 있고 배가 2.4 m/s보다 빠르면 뱃머리 양옆으로 와서 함께 간다.
- 원래 자리에서 400 m를 넘거나, 90초가 지나거나, 배가 2 m/s 아래로 느려지면 놓아준다. 놓아주면 잠수하지 않고 수면에서 숨 쉬고 뛰어오르며 돌아서 자기 길로 헤엄쳐 간다.
- 돌고래마다 직접 헤엄친다(`dolphinStep`): 초당 최대 1.3 rad로 돌고, 속도를 부드럽게 바꾸며, 목표보다 6 m 앞을 겨냥해서 맴돌지 않고 나란히 붙는다. 뱃머리 앞 4~11 m, 옆 1~5 m의 자리는 천천히 바뀌어 서로 자리를 바꾼다. 돌 때는 몸을 기울인다. 자기 길 3 m 안에 오면 서서히 끌려 들어가 공유 시간표로 이음매 없이 넘어간다.
수면과의 상호작용:
- **물 아래 그림자**(`undersea.js`): 물은 불투명하다. 그래서 생물을 위에서 작은 지도(512², 카메라가 보는 물 128 m)에 수면까지의 가까움으로 그린다. 바다 셰이더는 그 자리의 아래에서 올라오는 빛을 어둡게 한다. 깊을수록(9 m까지) 옅고 흐릿하고, 잔물결에 따라 일렁인다. 반사가 센 비스듬한 시선에서는 실제 바다처럼 하늘 반사에 가려진다.
- **물에 닿은 몸**: 물과 만나는 선에 끊어진 흰 거품이 생긴다. 막 물 밖으로 나온 부분은 젖어서 어둡고 반들거린다. 수위는 바다와 같은 파도 함수로 구한다.
- **물자국**(`ripples.js`, 64장을 돌려 씀):
  - 수면을 뚫고 나오거나 들어가면 흰 물(1.5초)과 고르지 않은 동심원 두세 겹(3초)이 생긴다.
  - 등이나 지느러미가 수면을 가르며 나아가면 뒤로 흰 물이 길게 끌린다.
  - 큰 고래(범고래·혹등고래)가 가라앉은 자리에는 매끈한 '고래 발자국'이 24초 남는다. 하늘을 더 고르게 비춰 밝고 유리 같다.
- **물보라**:
  - 물튀김은 구멍 가장자리에서 바깥으로 튀는 왕관과, 다시 떨어져 들어갈 때 가운데서 솟는 물기둥으로 되어 있다. 큰 것은 물안개를 남긴다.
  - 물 밖으로 솟은 몸에서는 0.9초 동안 물이 몸길이를 따라 떨어진다.
  - 물방울은 크기가 그대로이고 수면에 닿으면 사라진다. 숨 물보라와 물안개만 퍼진다.
  - 돌고래의 숨은 옅은 안개 한 번이다. 밤에는 물보라도 어둡다.
- 400 m나 90초 때문에 떠난 무리는 60초, 배가 느려져서 떠난 무리는 10초 동안 다시 오지 않는다.

### 시간과 날씨

- **낮밤**은 공유 시계의 1시간이 하루다(`DAY = 3600`). 매시 정각에 해가 뜨고 15분에 한낮, 30분에 노을, 45분에 한밤이다. 시간대와 상관없이 모든 플레이어가 같은 하늘을 본다. 온라인이면 서버 시계, 오프라인이면 기기 시계(UTC 초)를 쓴다.
- **구름**은 날씨를 따라 20초쯤에 걸쳐 바뀐다. 맑으면 듬성듬성하고, 돌풍이면 늘고, 비가 오면 하늘을 덮는다.
- **오로라**는 세 밤 중 하루꼴로 북쪽 하늘에 뜬다. 밤 번호(정오에 바뀜)로 정해서 모두에게 같다.
- **날씨**는 200초 단위로 바뀌고, 각 구간의 앞뒤 15%에서 서서히 들어오고 나간다.

| 날씨 | 비율 | 효과 |
|---|---|---|
| 맑음 | 40% | — |
| 산들바람 | 15% | — |
| 돌풍 | 15% | 실제 바람이 세진다. 흰 물결이 늘어난다 |
| 비 | 18% | 빗줄기, 수면의 빗방울 동심원, 빗소리. 바람도 조금 세진다 |
| 해무 | 12% | 안개가 짙어진다 |

- 비가 그친 다음 구간 앞부분에는 해를 등진 쪽에 무지개가 뜬다.
- 날씨도 공유 시계를 따라서 모두에게 같은 날씨다.

## 5. 항해

- 목표 속도는 W 7 m/s, 손을 떼면 3.2 m/s, S 1 m/s이고, 바람 세기와 배가 바람을 받는 각도에 따라 줄어든다. 바람을 등지면 가장 빠르다.
- 바람의 방향과 세기는 시간에 따라 천천히 바뀐다. 돌풍과 비가 세기를 더한다.
- 조타는 부드럽게 들어간다. 섬에 부딪힐 것 같으면 조타하지 않을 때만 살짝 비켜 가는 보조가 있다.
- **물에 뜨는 방식**(`boat-float.js`): 선체 다섯 곳의 물 높이로 오르내림·앞뒤·좌우 기울기의 목표를 잡고, 스프링으로 따라간다(주기 약 1.9 / 2.4 / 3.4초). 그래서 물마루에 늦게 반응하고, 조금 지나쳤다가 자리를 잡는다. 선체는 27 cm 잠긴다.
- **바람에 기울기:** 돛에 옆바람을 받으면 바람 반대쪽으로 기운다. 옆바람 세기의 제곱에 비례하고 최대 약 14°다. 빠르게 달리면 뱃머리가 조금 들리고, 돌 때는 안쪽으로 조금 기운다.
- **다른 배**도 같은 모델로 계산한다. 물결이 모두에게 같으므로 위치와 방향만 받으면 기울기를 알 수 있고, 통신량은 늘지 않는다.
- **항적**(`wake.js`)은 배가 지나간 길을 따라 켈빈 각(19.5°)으로 벌어지는 리본이다. 양옆은 가는 사선 물마루, 가운데는 흩어지며 사라지는 거품이다. 거품이 줄 때는 옅어지지 않고 조각 수가 줄며(옅은 흰색은 회색 얼룩으로 보인다), 조각 주변은 기포가 섞인 밝은 청록색이다. 리본 가장자리는 완전히 투명해서 이음새가 보이지 않는다. 밤에는 푸르게 빛난다. 가까운 다른 배 4척에도 항적이 생긴다. 지나온 길은 1.2 m마다, 그리고 0.05 rad 넘게 꺾일 때마다 점을 찍어서 선회가 촘촘한 곡선으로 남는다. 선회 안쪽에서는 퍼지는 항적이 회전 반경을 넘어 접히지 않게, 꺾인 정도에 맞춰 부드럽게 안으로 당긴다. 높이는 GPU에서 파도장으로 계산한다.
- **자동 항해(T)**(`autopilot.js`): 2.4 km 안에서 아직 지나지 않은 가장 가까운 섬(앞쪽을 우선)을 골라, 가까운 쪽 해안에서 45 m쯤 떨어져 지나간 뒤 다음 섬으로 간다. 앞 22·45·75 m를 몇 방향으로 살펴 육지와 지도 끝을 피하고, 목표가 350 m보다 멀면 빠르게 간다. 닿지 못하는 목표는 일정 시간 뒤 포기한다. 방향·속도 키를 누르면 바로 해제된다. 무작위가 없어서 누구에게나 같게 움직인다.
- **배 모델**(`tools/blender/boat.py` → `public/assets/blender/boat/boat.glb`, `npm run boat`): 5 m 오픈 데이세일러(슬루프). 현호와 플레어가 있는 둥근 선체, 움푹한 조종석과 벤치, 테이퍼진 마스트와 스프레더, 포스테이·백스테이·슈라우드, 구스넥에 걸린 붐, 러더와 틸러, 메인세일과 지브. 텍스처(방오 도료·부트 스트라이프·청록 선체, 티크 판재, 니스 칠한 나무, 패널 이음이 있는 돛천)는 스크립트가 numpy로 그려 GLB에 넣는다. 재질마다 메시 하나라서 배 한 척이 그리기 8회(+ 메인시트, 깃발)이고, 삼각형 약 4,800개, 256 KB다. 멀리서는 선체·갑판·마스트·돛만 합친 저상세 모델을 쓴다. 크기(길이 5 m, 폭 1.88 m, 갑판 0.74 m)는 물 셰이더의 선체 윤곽, 부력, 등불 위치와 맞춘다.
- **돛**(`wind-rig.js`): 메인세일은 마스트, 지브는 포스테이를 축으로 시트 각도만큼 돌고(지브는 0.8배), 겉보기 바람만큼 시위 길이의 약 1/8까지 부푼다. 바람을 정면으로 받으면 펄럭인다. 축은 돛 UV의 러프(u = 0)에서 찾는다. 붐은 구스넥에서 메인세일과 같이 돌고, 메인시트 줄이 붐 끝에서 트래블러로 따라간다. 러더와 틸러는 키 입력에 맞춰 함께 돈다. 가까운 다른 배 4척은 각자 자기 바람에 맞춰 돛이 움직인다.

## 6. 발견과 기록

- **항해 노트(J):** 이번 항해의 거리, 시간, 최고 속도, 만난 섬과 생물 종 수, 그리고 순간 기록. 웹에서는 "지금까지" 누적 기록(거리, 시간, 항해 횟수, 섬, 생물)이 이 브라우저의 localStorage에 남는다.
- **바다 도감(K):** 생물 7종의 스케치 카드: 잉크 실루엣, 설명, 만난 횟수(빗금, 10번이 넘으면 숫자). 아직 못 만난 생물은 흐린 연필 윤곽으로 보인다.
- **발견되는 순간:** 섬 도착(처음/다시), 처음 만난 생물, 고요한 만, 바다 위의 노을, 별이 뜬 밤바다, 오로라, 무지개, 안개의 끝.
- **사진 모드(C):** HUD가 사라지고 배는 항로를 유지한다. 카메라가 배 주위를 돈다(좌우 돌기, 상하 거리). Space로 PNG를 저장한다.

## 7. 함께하기

- **같은 바다:** 근처의 다른 배가 보인다. 다른 배 위에 이름표는 띄우지 않는다(돛만으로 충분하다). 배 이름은 주운 병 편지의 보낸 이로만 보이고, "형용사 + 명사 + 호"(예: 은빛 물새호 / the Silver Gull)로 자동으로 정해진다.
- **빛물결(E):** 배에서 빛이 번쩍한 뒤 빛의 물결 세 겹이 반경 약 17 m까지 천천히 퍼지며 사라지고, 빛 알갱이가 나선을 그리며 떠오른다. 4초 동안 보이고 5초마다 쓸 수 있다. 패킷의 경과 시간은 초 단위로 보내서, 빛물결 하나로 메시지가 몇 개만 더 나간다(서버 한도 초당 30개).
- **동행:** 다른 배와 5~34 m 거리에서 같은 쪽(방향 차 약 35° 이내)으로 함께 가면 약 6초 뒤 "잠시 같은 바람을 타고 있어요"가 뜨고 둘 사이에 빛이 돈다.
- **동행 연습(H):** 오프라인일 때 로컬 배 1척과 위 기능을 연습한다.
- **병 편지(B):** 정해진 문구 8개 중 하나를 골라 병을 띄운다. 서버가 셀마다 최대 100개를 30일 동안 보관하고, 띄우기는 30초에 한 번이다. 8 m 안으로 다가가면 병을 줍는다. 직접 쓰기는 60자까지이고, 서버가 TypeSafe AI의 Jev에 욕설(초성·숫자 섞은 변형 포함), 모욕·비방·혐오·성적 표현, 연락처·개인정보를 각각 예/아니오 확률로 묻고 하나라도 0.5 이상이면 띄우지 않는다(한국어 예문 21개로 맞춰 봤다: "미친듯이 예쁜", "개크다" 같은 감탄은 통과). 키가 없거나 검사가 실패하면 직접 쓴 편지는 띄우지 않는다. 검사는 소켓마다 4초에 한 번, 한 번에 하나다. 사람이 쓴 편지는 서브셋 글꼴에 없는 글자가 있을 수 있어 시스템 명조로 그린다. 다른 사람이 띄운 병은 금빛으로 숨 쉬듯 빛나고(병, 그 위의 빛무리, 수면의 빛 웅덩이), 멀리서도 몇 픽셀 이상으로 보인다. 바다 곳곳에는 전설 문구 16개가 든 "오래된 병"도 떠 있다. 문구는 번호로만 오가서 받는 사람의 언어로 보인다. 주운 병은 화면 아래 두 줄 알림(제목 / “문구”)으로 뜬다.

## 8. 그래픽

- **렌더러:** three.js 0.185.1(WebGL)을 `public/vendor/`에 넣고 import map으로 불러온다. ACES 필름 톤 매핑(노출 1.15)을 쓰고, HUD는 톤 매핑에서 뺀다. `?tone=none`으로 끌 수 있다.
- **품질 단계**(`quality.js`): 불러올 때 한 번 정한다. PC는 high, 짧은 변이 800 px 이상인 터치 기기는 medium, 휴대폰과 소프트웨어 GPU는 low. `?quality=low|medium|high`로 바꿀 수 있다.

  | 단계 | 섬 텍스처 | 가까운 섬 고밀도 메시 | 그림자 | 물 반사 | 나무 |
  |---|---|---|---|---|---|
  | high | 1024 | 있음(450 m 안) | 2048 | 화면의 0.5배 | 2.6배 |
  | medium | 1024 | 없음 | 1024 | 없음 | 1.8배 |
  | low | 512 | 없음 | 없음 | 없음 | 1.1배 |
- **섬 지형**(`terrain-material.js`): Poly Haven의 CC0 사진 텍스처 4묶음(풀, 바위, 모래, 젖은 물가, `assets/textures/terrain`)을 정점마다 실린 비율로 섞는다. 평평한 층은 위에서 한 번 투영하고, 바위만 세 방향으로 투영하며, 비율이 거의 0인 층은 읽지 않는다. 법선은 월드 공간에서 섞는다(UDN). 섬 종류의 색(화산섬의 검은 흙, 산호섬의 흰 모래)은 정점 색 틴트로 남긴다. 바위는 경사와 노이즈로 얼룩진 바위 지대가 된다. 출항 지점의 만도 같은 재질을 쓴다.
- **물 반사**(`reflection.js`, high): 장면을 수면 아래 거울 카메라로 화면 절반 크기에 한 번 더 그리고(물·하늘·비·물속 생물은 빼고), 바다 셰이더가 물결로 휘고 세로로 번지게 해서 수식으로 계산한 하늘 반사 위에 얹는다. 그림자 지도는 메인 패스 것을 다시 쓴다.
- **그림자**(medium 이상): 해(밤에는 달) 방향 광원 하나가 카메라 앞 220 m를 중심으로 ±260 m를 덮는다. 그림자 텍셀 단위로 옮겨서 가장자리가 떨리지 않는다. 섬, 나무, 배가 드리우고 받는다.
- **나무:** 잎 카드의 법선을 수관 중심에서 바깥으로 돌려 나무 전체가 하나의 잎 덩어리로 빛을 받고, 뒷면도 법선을 뒤집지 않는다. 해를 등진 쪽에는 잎을 통과한 빛이 은은하게 더해진다. 섬 나무의 줄기는 면을 줄인 가벼운 줄기(약 50 삼각형)를 쓴다.
- **바다 셰이더**(`ocean-material.js`)
  - 큰 너울 5개(`wave-field.js`). 배의 부력도 같은 식으로 계산해서, 배가 보이는 물결 그대로 출렁인다.
  - 잔물결 6옥타브. 방향을 황금각으로 흩고, 옥타브마다 자기 파장 크기의 노이즈로 휘며, 구역마다 세기가 달라서 줄무늬가 생기지 않는다. 픽셀보다 가는 옥타브는 건너뛴다.
  - 프레넬 하늘 반사. 하늘과 바다가 같은 햇빛 번짐을 써서 노을에 금빛 길이 생긴다.
  - 미세면(microfacet) 햇빛 반짝임, 밤에는 달빛 반짝임.
  - 얕은 물빛과 물결 무늬(코스틱), 너울 꼭대기로 비치는 청록빛.
  - 해변 거품, 바람 방향으로 결이 진 흰 물결(장면 밝기에 맞춰 어두워짐), 비 올 때 빗방울 동심원(카메라 가까운 곳만).
  - 흰 물결은 바람이 셀 때만 생긴다. 너울 꼭대기(초속 6~9 m로 달림)에 묶여 있던 거품이 흰 얼룩처럼 빠르게 미끄러져 보여서, 꼭대기가 부서진 자리에 거품을 남기고 약 2초에 걸쳐 사라지게 했다.
  - 선체 주변(내 배와 가까운 다른 배 3척): 뱃머리 물결 언덕과 양옆 물마루, 선체가 하늘을 가려 어두워진 반사. 선체 둘레 거품은 회색 얼룩처럼 보여서 뺐다.
  - 거리 안개.
- **수면 메시**(`water-lod.js`): 200 m 타일 9×9개를 배를 따라 옮긴다. 거리에 따라 3단계 상세도를 고르고, 시야 밖 타일은 그리지 않는다.
- **하늘**(`sky.js`): 하늘 돔과 바다 반사가 같은 GLSL을 쓴다. 그래서 바다에 같은 노을과 구름이 비친다.
  - 낮에는 짙은 파랑에서 밝은 수평선으로. 노을에는 해 쪽이 금빛이고 반대쪽이 장밋빛이며(비너스 띠), 해가 진 쪽 수평선에 잔광이 남는다. 해가 수평선에 닿을 때 빛이 가장 붉다.
  - 해 원반과 노을빛 빛살. 구름층은 해(밤에는 달) 쪽 가장자리가 밝고, 노을에는 금빛과 분홍, 밤에는 어두운 실루엣에 달 쪽만 은빛이다.
  - 밤: 지평선에서 솟는 은하수와 먼지 띠, 반짝이는 별(밝은 별은 색이 있다), 별똥별(19초 구간마다 한 번, 0.8초), 달무리, 때때로 오로라. 별은 하루에 한 바퀴 돈다.
  - 노이즈는 256² 격자 텍스처 한 장을 선형 필터로 읽는다. 옥타브 하나가 사인 해시 넷 대신 텍스처 한 번이다. 바다 반사의 구름은 2옥타브이고, 물이 하늘을 거의 비추지 않는 가까운 곳(프레넬 < 0.04)에서는 건너뛴다.
  - 그 밖에 빗줄기(정점 셰이더로 계산, 그리기 1회), 무지개, 달 원반.
- **밤의 빛:** 해변에서 부서지는 파도가 푸르게 빛나고(발광 플랑크톤), 배 주변 수면 위로 작은 빛 140개가 떠올랐다 사라진다(`motes.js`, 대부분 청록, 몇 개는 금빛). 항적도 은은하게 빛난다.
- **등불**(`lantern.js`): 모든 배의 좌현 선미 티크 기둥에 놋쇠 등불이 걸려 노을부터 해 뜰 때까지 켜진다(`env.night` 0 → 0.35에서 밝아짐, 비에 30% 어두워짐). 배마다 위상이 다르게 사인 합으로 깜빡인다.
  - 내 배에만 실제 조명(PointLight, 거리 7 m)이 하나 있다. 처음부터 씬에 두고 세기만 바꾸므로 재질 재컴파일이 없다. 등불은 선체가 기울어도 연직으로 매달려 살짝 흔들린다.
  - 다른 배는 조명 없이 가산 합성 빛무리만 쓴다. 멀어도 몇 픽셀을 유지해 밤바다에 따뜻한 점으로 보인다.
  - 바다 셰이더가 가까운 배 4척(vessels 슬롯)의 등불 위치를 계산해, 물 위에 따뜻한 빛 웅덩이와 물결에 반짝이는 반사 줄기를 그린다.
- **깃발**(`wind-rig.js`): 돛대 끝의 0.55 m 테라코타색 삼각기가 겉보기 바람 방향으로 날리고, 바람이 셀수록 빨리 펄럭인다.
- **조명:** 방향광 하나가 낮에는 해, 밤에는 달 쪽에서 오는 푸르고 약한 달빛이다.
- **카메라:** 배 뒤 14 m, 높이 6 m에서 9 m 앞 2.3 m 높이를 본다. 수평선이 화면 위에서 3분의 1쯤에 와서 하늘이 넉넉히 보인다.
- **성능 조절:** 웹에서는 FPS가 46 아래면 해상도 배율을 낮추고, 57을 넘으면 다시 올린다(0.6배 ~ 기기 배율, 휴대폰은 최대 1.5배). 먼 배는 저상세 모델로, 시야 밖 나무는 그리지 않는다.
  - 만의 나무와 바위는 재질별로 한 메시로 합친다(잎 카드마다 그리던 약 2,000회의 그리기 호출이 사라졌다).
  - 해양 생물은 수면 근처 개체만 메인 패스에서 그린다. 물속 개체는 불투명한 바다에 가려지므로 물속 그림자 지도에만 그린다.
  - 개발자 도구에서 `__seaTimeShift = 초`로 다른 시각을 볼 수 있다.
- **소리**(`audio.js`): 파일 없이 합성하고, 화면에 보이는 것에서만 난다. 음악은 없다. AudioContext 하나에 마스터 → 리미터 한 줄이고, M으로 끄며(이 브라우저에 기억) 탭이 가려지면 멈춘다.
  - 바탕: 두 개의 느린 LFO로 불규칙하게 오르내리는 낮은 너울, 겉보기 바람(돌풍, 바람이 오는 쪽으로 살짝 치우침), 속도에 따라 커지는 뱃전 물소리, 맞바람(돛 효율이 낮을 때) 돛 떨림, 비.
  - 배: 실제 피치·히브에서 나오는 찰랑임과 뱃머리 철썩임, 롤이 방향을 바꿀 때 가끔 삐걱임(9~20초에 한 번 이하), 갑판의 빗방울. 삐걱임은 초당 70~120번의 마찰을 나무 울림 두 대역으로 걸러 한 음으로 들린다. 초당 24~40번일 때는 '두두두둑' 하는 떨림으로 들렸다. 돛 펄럭임은 바람을 거의 정면으로 받을 때만, 느리고 고르지 않게 난다.
  - 세계: 고래 숨과 노래, 갈매기, 돌고래 휘파람, 해안 200 m 안의 파도. 카메라 기준으로 좌우가 나뉘고 멀수록 작고 어두워진다.
  - 행동: 빛물결은 작은 유리 소리, 병 띄우기(코르크와 퐁당), 병 줍기(종이), 노트·도감(책장), 처음 만난 섬·생물(세 음).
  - 크기(헤드리스 Chrome 실측): 순항 −35 dBFS RMS, 전속 −32, 비 −32~−30. 신호 하나의 최댓값은 −20~−32 dBFS.

## 9. 다국어

- `public/src/i18n.js`가 언어를 정한다. 브라우저 언어가 한국어면 `ko`, 아니면 `en`이고, `?lang=ko|en`으로 바꿀 수 있다.
- 한국어 원문을 키로 영어 표를 찾고, 영어가 없으면 한국어를 그대로 보여준다. 새 언어는 표 하나를 추가하면 된다.
- 섬과 배 이름은 한/영 쌍을 같은 시드로 골라서 위치와 정체성은 같고 표시만 바뀐다.
- 서버는 이름이 비어 있으면 빈 값을 보내고, 받는 쪽이 자기 언어로 "이름 없는 배 / Unnamed boat"를 보여준다.
- 다른 플레이어가 정한 배 이름은 그 사람의 언어 그대로 보인다.

## 10. 멀티플레이 서버

자세한 내용은 [README.md § 멀티플레이 서버](../README.md)에 있다.

- Cloudflare Worker가 정적 파일과 `/ws`, `/health`를 맡는다.
- 바다를 2 km 셀로 나누고, 셀 × 채널(1~64)마다 Durable Object 하나가 맡는다. 셀에 200척이 차면 다음 채널로 옮긴다.
- 자기 셀에는 위치를 게시하고(초당 15번), 경계 850 m 안의 이웃 셀은 구독만 한다(위치는 초당 2번, 최대 소켓 4개). 구독 거리가 시야(800 m)보다 넓어서 경계 너머 배도 같은 거리에서 보인다.
- 10 Hz 틱마다 각 시청자 주변 800 m 안의 가까운 48척만 바이너리로 보낸다(한 척 17바이트). 800 m 밖의 배는 초당 1번 위치만 보내고, 수평선의 먼 등불로 그린다(`far-sails.js`).
- 클라이언트는 150 ms 뒤 위치를 보간해 그리고, 스냅샷이 늦으면 최대 0.4초 이어서 미끄러진다. 배는 1.6초에 걸쳐 나타나고, 사라질 때는 1.4초 동안 흘러가며 흐려진다. 가까운 64척만 그린다.
- 공유 시계: 서버 시각을 받아 모든 플레이어가 같은 초를 쓴다.
- 비용: 게시된 배가 없는 셀은 틱을 멈춰 잠든다(구독만 걸린 셀도). 10초 동안 아무것도 보내지 않은 소켓은 서버가 끊는다(4408, 백그라운드 탭). 클라이언트는 게임이 다시 위치를 보낼 때 다시 붙는다.
- 제한: 소켓당 초당 메시지 30개, 이름은 제어 문자를 지우고 16자, 세계 밖 위치 무시, 같은 id 중복 접속 거절.
- 디버그 배: `npm run bots`(staging 전용)가 내 배를 찾아 주변에 배를 띄우고 따라다닌다(`tools/sea-bots.mjs`).

## 11. 개발자 도구

- localhost에서, 또는 공개 사이트에서 `?dev=<키>`로 연 브라우저에서만 보인다. 키는 `.dev-key`에 있고(git 제외) 페이지에는 해시만 들어간다. `?dev=off`로 끈다.
- **G 그래픽 패널:** FPS, 해상도 배율, 그리기 횟수, 삼각형 수, 섬·생물 로딩, 시야 제외 수, 위치, 네트워크 상태.
- **P 성능 시험:** 로컬 봇 0/16/64/128척으로 최적화 전후를 비교 측정하고 결과를 저장한다.
- 콘솔에서 `window.__sea`로 장면, 배, 세계, 소셜 상태를 볼 수 있다.

## 14. 알려진 한계와 할 일

- 휴대폰 실기기에서 FPS와 화면 배치를 아직 확인하지 않았다. 바다 셰이더가 픽셀마다 노이즈를 더 계산하므로 저사양 기기에서 프레임이 떨어질 수 있다.
- id를 클라이언트가 정해서 다른 사람인 척하는 것을 막지 못한다. 계정이 필요해지면 Worker가 서명한 토큰으로 id를 발급하는 단계를 추가한다.
- 병 편지는 채널마다 따로 보관된다. 채널 간 공유가 필요하면 셀 단위 저장 Durable Object를 따로 둔다.
- 셀 Durable Object는 처음 접속한 사람 근처 데이터센터에 생기는 것으로 알려져 있다(Cloudflare 일반 동작). 같은 셀에 다른 대륙의 플레이어가 있으면 그쪽은 지연이 클 수 있다.
- 돌고래 놓아주기 값(400 m, 90초)과 바람에 기우는 정도(최대 약 14°)는 실제로 타 보고 조정이 필요하다.
- 소리는 헤드리스 Chrome에서 크기만 측정했고 사람이 들어 보지 않았다. Safari·iOS도 확인하지 않았다.
- 파도에 뱃머리가 박힐 때의 물보라는 아직 없다.
- 공개 도메인이 아직 없다.
- 새 하늘·등불·밤의 빛은 4K(3840×2160)에서 프레임당 낮 약 1.5 ms, 노을 1.2 ms, 밤 0.4 ms를 더 쓴다(이 Mac 헤드리스 측정: 76 → 68, 65.8 → 60.8, 60.3 → 58.8 fps). 느린 기기는 해상도 자동 조절이 받아 주지만, 휴대폰 실기기에서는 확인하지 않았다.
- 헤드리스 페이지 3개를 2배 해상도로 동시에 돌리는 무거운 조건에서 HUD 패널이 작아진 복사본으로 남는 현상을 한 번 봤다. 원인으로 보이는 것은 2026-11-08에 고쳤다. three.js가 HUD 텍스처를 처음 크기로만 잡아 두는데, 해상도 자동 조절이나 전체화면으로 캔버스 크기가 바뀌면 그림이 맞지 않았다. 이제 크기가 바뀔 때 텍스처를 다시 잡는다. 같은 조건에서 다시 확인하지는 않았다.
